# House of YVN

Luxury editorial website for House of YVN, a private styling studio by Yvonne.

## Local preview

Open `index.html` directly, or serve the folder with any static file server.

## Deployment

The repository includes `netlify.toml` and can be deployed directly to Netlify with no build command. The publish directory is the repository root.

## Content to personalise

- Replace the generated editorial imagery in `assets/` with final brand photography when available.
- Confirm the enquiry email and Instagram URL in `index.html`.
- Connect `www.houseofyvn.com` after the Netlify site is live.
